# Roadmap belajar 7 hari

Gunakan 2–3 jam per hari: 30 menit membaca, 60–90 menit praktik, 30 menit menjelaskan ulang dan menguji. Jika masih baru tooling, tambah satu hari khusus instalasi; jangan menebak solusi karena mengejar jadwal.

| Hari | Fokus                   | Praktik                                      | Bukti selesai                                             |
| ---- | ----------------------- | -------------------------------------------- | --------------------------------------------------------- |
| 1    | Setup dan dasar Kotlin  | Instal tools, jalankan basics, latihan 01–08 | Bisa menjelaskan val/var, loop, nullable, edge case       |
| 2    | Nested loop dan pola    | 12 pola, trace diamond n=4, simulator        | Bisa menurunkan batas kiri/kanan tanpa hafalan            |
| 3    | Algoritma               | Latihan 09–13 dan 26–30, tulis test          | Bisa menjelaskan invariant dan kompleksitas               |
| 4    | SQL dasar dan relasi    | Schema/seed, latihan SQL 01–18               | Bisa memilih INNER vs LEFT, WHERE vs HAVING               |
| 5    | SQL lanjut dan backend  | SQL 19–35, health/readiness, tes API         | Bisa menjelaskan ranking seri, prepared query, pagination |
| 6    | Flutter CRUD            | Emulator, list/detail/form/delete, test      | CRUD sampai MySQL dan pesan validasi benar                |
| 7    | Simulasi technical test | Kerjakan paket ujian tanpa solusi            | Semua checks lulus dan bisa menjelaskan tradeoff          |

## Tiga jalur mandiri

**Kotlin:** basics → rumus pola → simulator → algoritma → latihan → tes. **MySQL:** schema → seed → fundamental → join/agregat → CTE/window → EXPLAIN → latihan. **Flutter:** tooling → API siap → arsitektur → list/detail → mutation → error/refresh → tes perangkat.

Catat kesalahan dalam jurnal: gejala, hipotesis, bukti, perbaikan, dan cara mencegahnya. Ulangi soal yang gagal 24 jam kemudian tanpa membuka solusi. Jika bisa menjalankan contoh tetapi belum bisa menjelaskan rumusnya, ulangi dengan n=2 dan n=3 di kertas.
